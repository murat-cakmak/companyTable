# Add Shadcn Component

1. Open your terminal in the project directory.
2. Use the `npx` command to add a component. Replace `[component-name]` with the name of the component you want to add (e.g., `button`, `input`, `dialog`).

```bash
npx shadcn@latest add [component-name]
```

3. The component will be installed in `components/ui`.
