# Internationalization (i18n)

This project uses `next-intl` for internationalization.

## Structure

- **Start**: `middleware.ts` handles locale detection and routing.
- **Config**: `i18n/request.ts` and `i18n/routing.ts` define available locales (`en`, `tr`) and default locale (`en`).
- **Messages**: 
  - `messages/en.json`: English translations.
  - `messages/tr.json`: Turkish translations.
- **Components**:
  - `components/LanguageSwitcher.tsx`: Dropdown to switch languages.
  - Updated `components/AppHeader.tsx` and `components/ExcelTable.tsx` to use translations.

## Adding Translations

1. Add the key-value pair to `messages/en.json`.
2. Add the corresponding key-value pair to `messages/tr.json`.
3. In components:
   ```tsx
   import { useTranslations } from 'next-intl';
   
   // ...
   const t = useTranslations('Namespace'); // e.g. 'Common' or 'Table'
   
   return <div>{t('key')}</div>;
   ```

## Routing

- Use `Link` from `@/i18n/routing` instead of `next/link`.
- Use `usePathname`, `useRouter` from `@/i18n/routing`.
- Pages are located in `app/[locale]/`.
